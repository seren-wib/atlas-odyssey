# 2026-10-15 진행 사항·할 일

## 오늘 결정한 것

### 주제

1인 스튜디오 사이트 + 외주 상품 카탈로그·접수·결제·진행 추적. 본인 전용(멀티테넌트 아님).

- 문제 정의: 혼자 외주를 받을 때 접수·견적·입금·진행 상황이 메일·메신저·스프레드시트로 흩어지는 것을 한 곳에 모은다.
- 게임 판매는 itch.io·Steam에 맡긴다. 사이트는 소개·포트폴리오와 외주 흐름에 집중한다.
- 한국어/영어 2개 언어. 처음부터 적용한다.

### 기능 범위 (우선순위 순)

1. 소개·포트폴리오·데브로그
2. 외주 상품 카탈로그 — 프리랜서가 흔히 맡는 업무를 상품으로 등록 (이름 / 설명 / 기간 / 가격·통화)
3. 의뢰 접수 — 상품 선택 + 세부(예산 / 기간 / 설명 / 첨부) + 메일 알림
4. 로그인 — 비밀번호 없음 (매직링크 또는 Google). 의뢰인이 자기 의뢰 상태 열람
5. 견적 → 선금 결제 — `PaymentProvider` 추상화 아래 토스페이먼츠(KRW)·PayPal(USD). 상품 통화로 분기. 둘 다 테스트/샌드박스. 토스 먼저, PayPal 다음
6. 진행 상태 추적 — 접수 → 견적 → 선금 → 진행 중 → 납품 타임라인
7. 작업 상태·일정 조회 AI 봇 — Claude API + tool use. 읽기 전용, 로그인 사용자 범위로 제한, 요청 횟수 제한

일정: 중간 발표(11월 초)까지 1·2·3 + 배포 레일. 최종 발표(12월 말)까지 4~7.

### 스택

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 프레임워크 | Next.js | 프론트·백·결제 웹훅을 한 프로젝트로. 혼자 하기에 가장 덜 찢어짐 |

| 인증 | Auth.js | 비밀번호 없는 로그인 |
| 결제 | 토스페이먼츠(테스트), PayPal(샌드박스) | 국내·해외 의뢰인 모두 대응. 사업자 등록 전까지 테스트 모드 |
| AI | Claude API | 상태·일정 조회 봇. 모델은 구현 시 확인 |

### 인프라

- Oracle Cloud Always Free ARM A1 (서울, 재고 없으면 춘천)
- Caddy — HTTPS 인증서 자동 발급·갱신. 80/443 받아서 Next.js 컨테이너로 프록시
- Docker Compose — 앱 + Postgres(named volume) + Caddy
- Postgres 일일 `pg_dump` cron
- `main` 머지 시 GitHub Actions → SSH → `docker compose pull && up -d`. 앱 컨테이너 전 마이그레이션 단계 포함
- 시크릿: GitHub Secrets → 배포 시 서버 `.env`
- 도메인: Cloudflare Registrar (원가 판매, 갱신가 동일)
- 첨부 파일: Oracle Object Storage(무료 10GB) 검토 중
- 예비: Oracle 재고 확보 실패 시 GCP e2-micro + 외부 Postgres(Neon/Supabase 무료 티어). e2-micro는 1GB라 앱·DB 동거 불가
