# atlas-odyssey

A personal learning atlas. Put what you have learned on one map, level by level, and see how much you know and what is still left.

Entry for the CBNU CUVIC Vibe Coding Contest 2026 (individual).

## Idea

- The map has six levels: field, roadmap, part, section, subsection, item.
- Each item gets a level (1 heard of it, 2 can explain the concept, 3 knows the theory, 4 has built it), an in-progress flag, and evidence. Level 4 needs evidence.
- AI reads what you already left behind (commits, blog posts, class notes) and proposes records. Nothing is saved until you confirm it in the UI. The UI is the only write path.
